# 校园二手交易小程序 - 用户认证模块

## 项目概述
本项目是一个校园二手交易小程序的用户认证模块，实现了基于学号的用户登录与注册功能，为校园二手交易提供身份验证基础。

## 功能特点

### 登录功能
- 采用学号作为核心认证凭证
- 支持密码验证登录
- 登录成功后自动跳转到个人中心页面
- 支持自动登录状态保持

### 注册功能
- 支持新用户注册
- 需验证手机号（含验证码功能）
- 包含完整的表单验证（学号唯一性、手机号格式、密码长度等）
- 注册成功后自动跳转至登录页面

### 个人中心
- 显示用户基本信息（姓名、学号）
- 提供功能入口（二手交易、个人设置）
- 支持退出登录功能

## 技术栈
- 微信小程序原生开发
- 使用微信小程序提供的本地存储API
- 采用Promise处理异步操作

## 使用说明

### 导入项目
1. 下载本项目所有文件
2. 打开微信开发者工具
3. 点击"导入项目"
4. 选择项目根目录
5. 使用测试AppID（或您自己的AppID）
6. 点击"导入"

### 注意事项
- 本项目为前端演示版本，所有数据存储在本地
- 实际应用中，应连接真实后端API进行用户认证
- 验证码功能目前仅在控制台打印，实际应用中应集成短信发送服务

## 开发说明
- 如需扩展功能，请在app.js中添加全局方法
- 页面样式可在各自的wxss文件中修改
- 项目使用rpx单位，支持不同尺寸的设备
